Privacy policy

Personal Drive Backup · Last updated October 23, 2026

Access and purpose

This private, single-user utility accesses only Google Drive files created or explicitly used with this application, using the drive.file OAuth scope. It copies files selected by the owner and retains prior versions in the owner's Drive account.

Data storage and sharing

Backup files remain private in the owner's Google Drive. This information site does not contain or serve backup files, research data, passwords, client secrets, access tokens or refresh tokens. The utility does not sell user data, use it for advertising, or disclose it to an additional analytics service.

Credentials and control

OAuth credentials are stored in a private configuration directory on the owner's computer. Access can be revoked in the Google Account's third-party connections settings. Revoking access stops future backups; previously uploaded files remain in the owner's Drive until the owner chooses to manage them.

This information site

This static page has no application-side forms or analytics. The hosting provider may process ordinary request metadata under its own policies.
