Personal Drive Backup

This is a private, single-user backup utility running on its owner's computer. It uses rclone to copy selected local files into the owner's Google Drive. It is not a service offered to the public.

How it works

The owner selects local files and authorizes access to their own Google Drive. Scheduled copies preserve prior versions. Backup files remain private in the owner's account.

About this page

This website provides application information and a privacy policy. It contains no backup files, research data or credentials.
